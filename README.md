# bdog563.github.io

Brandon Marks's personal site, served by GitHub Pages at https://bdog563.github.io/.
Plain HTML and CSS: `index.html` (About), `projects.html`, `style.css` (colors are tokens at the top), and `theme.js` (light/dark toggle).

## Add a profile photo
1. Put a square photo in this folder as `photo.jpg`.
2. In `index.html`, replace `<div class="avatar" aria-hidden="true">BM</div>` with
   `<div class="avatar"><img src="photo.jpg" alt="Brandon Marks"></div>`.

## Add a project
Copy the `<li>` inside `<ul class="projects">` in `projects.html` and change its link, picture and text.
